# 全屏与最大化窗口状态

状态：resolved（2026-11-27）
记录：2026-11-23

## 现象

- Windows 上按 `F11` 进入全屏，退出应用后再次启动，不是全屏。
- 需求变更：不需要恢复全屏；需要记住**最大化**状态与窗口尺寸/位置。

## 处理

- 移除 `F11` 全屏与全屏持久化，避免窗口控件被全屏状态藏住。
- 启动时恢复 `window_maximized`、`window_size`、`window_pos`。
- 窗口位置离屏时自动夹回 `(40, 40)`。
- 窗口状态最多每秒写一次设置，避免拖动窗口时刷盘。
- 实测：最大化 → 重启仍最大化；取消最大化 → 重启为普通窗口；离屏坐标启动后被夹回可见区域。
