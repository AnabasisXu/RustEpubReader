# 全屏与最大化窗口状态未记忆

状态：needs-triage  
记录：2026-11-23

## 现象

- Windows 上按 `F11` 进入全屏，退出应用后再次启动，不是全屏。
- 需求变更：不需要恢复全屏；需要记住**最大化**状态与窗口尺寸/位置。

## 期望

- 最大化 → 退出 → 启动：保持最大化。
- 普通窗口调整尺寸/位置 → 退出 → 启动：恢复上次尺寸与位置。
- 不再依赖 `F11` 全屏记忆。

## 可能原因

- 启动时 `ViewportBuilder::with_fullscreen` 在 Windows/winit 首帧未生效。
- settings.json 按启动工作目录定位；通过文件关联启动时工作目录可能不同。
- 最大化状态目前完全没有保存或恢复。

## 验收

- 最大化后重启仍最大化。
- 普通窗口重启恢复尺寸与位置。
